# 轻读

macOS 原生微信读书悬浮窗口，使用 Swift / AppKit / 系统 WebKit。无需安装第三方运行时。适用于 macOS 13 及以上；本地构建产物对应当前 Mac 架构。

## 打开

在 Finder 打开 `build/轻读.app`。第一次在窗口内登录微信读书，之后由 WebKit 保留登录状态。应用没有 Dock 图标，窗口只显示网页，不带应用工具栏。调好的参数会自动保存，重启后继续沿用。

微信读书网页负责书架、阅读进度、笔记和时长；本应用不调用私有同步接口，不会将网页凭据写入项目文件。仅额外保存外观设置、窗口位置和最后一个官方阅读页地址。网页 Cookie 使用系统 WebKit 本地持久化存储，与 Safari 的登录状态独立。

## 操作

| 操作 | 方式 |
| --- | --- |
| 全局隐藏／显示 | 默认 `Command + 0`（主键盘数字 0）；本次更新会将旧组合切换为此组合 |
| 更换全局快捷键 | 设置 → 全局快捷键，也可选 `Option + Space`、`Control + Option + Space` 或 `Shift + Command + R` |
| 隐藏窗口 | 全局快捷键，或窗口内 `Command + W` |
| 翻页 | 阅读区获得焦点后按 `←`／`→`，上一页／下一页按钮已隐藏 |
| 刷新 | `Command + R`，或设置菜单中的重新加载 |
| 移动、缩放 | 按住 `Option` 拖动阅读区移动，拖动窗口边缘缩放 |
| 设置 | 菜单栏书本图标，或窗口内 `Command + ,` |
| 完全透明阅读背景 | 默认已开启，背景不透明度 0%；本次更新会应用到旧配置 |
| 某些书籍仍有底色 | 使用整个窗口不透明度（文字也会变淡），或恢复易读外观 |
| 隐藏菜单栏入口 | 设置 → 隐藏菜单栏图标；需要有可用的全局快捷键 |
| 找回入口 | 从 Finder 再次打开 app，恢复窗口和菜单栏入口 |
| 退出 | 设置 → 退出轻读，或窗口内 `Command + Q` |

阅读窗口显示时浮于普通应用窗口之上。隐藏使用原生 `orderOut`，不会变成 Dock 中的最小化缩略图。活动监视器仍可看到进程；不保证盖过系统安全界面或在系统整体卡死时立即响应。

正文固定为金色 `#D4AF37`，同时适配普通文字与官方正文 Canvas 层，插图和封面保留原色。金色文字、隐藏翻页按钮与背景透明开关独立；左右方向键继续使用网页自身的翻页逻辑。

阅读页使用 100% 缩放，普通文字和 Canvas 字号均为此前 50% 缩放时的两倍；阅读页中的其他网页元素也随页面比例恢复，书架和独立登录页保持正常比例。正文行高设为 1.55 倍，段间距收紧为 0.6em；排版样式在网页脚本运行前注入，避免首轮测量和后续 Canvas 翻页使用不同的文字尺寸。移动窗口仍使用 Option + 拖动。

透明样式只调整官方阅读页背景，书架、登录框、笔记弹窗保留正常背景。网站布局变更及特殊书籍渲染可能影响效果，可关闭透明背景。金色文字在较暗的背景上更清晰。

原生 WebKit 底色通过经过运行时检查的 `drawsBackground` SPI 关闭（[WebKit 接口说明](https://bugs.webkit.org/show_bug.cgi?id=221663)）；这不是公开 API，当前本地应用使用并通过实际像素 alpha 验证，系统升级后应复测。接口不可用时会显示说明，不会静默声称已透明。

## 性能

- 只有一个网页容器，使用系统 WebKit，不打包 Chromium。
- 不做定时轮询、自动刷新、截图或文字识别。
- 隐藏首先移除原生窗口，再处理菜单、弹窗和焦点，不等待 JavaScript、网络或进度同步。
- 隐藏后保留网页以便立即恢复；不会强行终止网页进程。网页本身仍可能占用几百 MB，具体随书籍及页面变化。
- 不保证隐藏后的阅读时长统计：由微信读书网页及 WebKit 的可见性处理决定。

2026-09-28 在本机 macOS 26.3 的一次快照：原生进程 physical footprint 40.6 MB，WebContent 377.3 MB，GPU 21.3 MB，Networking 18.9 MB，合计约 458 MB。空闲 CPU 快照约 0–0.2%。这些是一次实测，不是上限，不能只看主进程内存代表全部占用。

隔离测试中，确认网页 JavaScript 已开始连续忙碌 2 秒后，原生隐藏调用实测 4.27 ms，低于测试要求的 500 ms，恢复及再次隐藏通过。这测量的是隐藏调用耗时，不是按键到屏幕消失的端到端时延，也不代表系统内存耗尽时的保证。

## 开发与验证

```bash
bash scripts/test.sh
bash scripts/test-window.sh
bash scripts/test-appearance.sh
bash scripts/build-app.sh
```

仅需 Apple Command Line Tools。测试采用独立 Swift 可执行程序，不依赖 XCTest 或完整 Xcode。产物是本地 ad-hoc 签名 app，没有公证；不包含安装、生产部署或对外发布步骤。

已验证：编译、20 项策略检查、7 项原生快捷键注册／冲突／重试检查、网页忙碌时隐藏／恢复、签名校验、官方首页与阅读页实际显示。独立 Swift 代码审查发现的 URL 凭据持久化、快捷键重试和图标解包问题已修复。

金色外观通过离线 WebKit 夹具验证：DOM 正文颜色、正文 Canvas 实际渲染像素、翻页按钮隐藏、外围界面不受影响、重复注入不产生重复节点。方向键检查确认没有额外接管按键，不等同于真实书籍的翻页实测。Canvas 滤镜会增加少量合成工作，未做长章节性能测量。

仍需在登录账号后人工确认：阅读几页后查看手机进度、创建笔记后查看手机笔记；全局快捷键在日常应用、多桌面和全屏应用中的表现。不会在未验证前声称跨设备同步已通过。

阅读页隐藏官网顶部导航和侧边、底部工具栏，保留标题与阅读内容。左右方向键翻页；需要返回书架时，按 ⌘, 选择原生菜单中的「回到微信读书首页」。

正文采用苹方（PingFang SC）中等字重，金色字带细暗色轮廓，改善复杂桌面背景上的辨识度；背景仍完全透明。
