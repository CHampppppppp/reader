# 轻读：上班时，给知识留一个小窗

> 工位上有两种窗口：正在赶的进度，和正在读的书。轻读负责后者；前者还得靠你。

轻读是一个 macOS 原生微信读书悬浮窗口。它用系统 WebKit 打开[微信读书官网](https://weread.qq.com/)，让书页浮在桌面上；不另造书架，也不接管你的阅读进度。窗口可以一键隐藏和恢复，适合在任务间隙读两页。至于这算不算摸鱼，请参考你的工作安排。下文的下载、功能和性能数据均指 macOS 版；Windows 原型的区别见下方说明。

仓库另有 **Windows 11 x64 第一阶段原型**（C# / WPF / WebView2），用于验证透明窗口、金色正文和繁忙网页下的原生隐藏，尚不是功能齐全的 Windows 正式版。默认显示离线夹具，`--website` 才打开官网；详见 [Windows 构建与验收说明](windows/Tests/Reader.Windows.Tests/README.md)。Windows 离线自动测试已在实机通过，桌面透明合成、输入和官网模式仍待人工验收；下文安装包和操作均针对 macOS。

## 项目目录

- `mac/`：macOS 源码、Swift 包定义、资源、测试与构建脚本，产物在 `mac/build/`。
- `windows/`：Windows 源码、资源、测试与构建脚本，产物在 `windows/build/`。
- 两个平台各自保存 `Resources/appearance.js`，构建时读取自己的副本，可分别调整外观。

以下开发命令均从仓库根目录执行。旧根目录 `build/` 中的历史产物保留，新产物使用上述平台目录。

## 先领一份“工位装备”

从 [Releases](https://github.com/CHampppppppp/reader/releases) 下载 `Reader-v0.1.0-macos-arm64.zip`，解压后打开 `轻读.app`。目前的安装包只支持 **Apple Silicon Mac**，要求 **macOS 13 或更新版本**；本仓库为私有仓库，下载需要仓库访问权限。

这个预览版使用临时签名，**没有 Developer ID 签名，也没有经过 Apple 公证**。macOS 可能拒绝首次打开。请先核对下载来源和 [Release 说明中的 SHA-256](https://github.com/CHampppppppp/reader/releases/tag/v0.1.0)；如果决定运行，尝试打开一次后，到「系统设置 → 隐私与安全性」选择「仍要打开」。不想手动允许的用户，需要等待未来提供正式签名和公证版本。

启动后阅读窗口默认隐藏；按 `Command + 0` 或使用菜单栏入口显示窗口，再登录微信读书。登录状态由系统 WebKit 在本机保存，和 Safari 的登录状态分开；没有“把扫码结果交给轻读保管”的环节。

## macOS 摸鱼操作手册

| 你想做什么 | 怎么做 |
| --- | --- |
| 让书页出现或消失 | 默认 `Command + 0`（主键盘数字 0），全局生效 |
| 换一个顺手的暗号 | 设置 → 全局快捷键；可选 `Option + Space`、`Control + Option + Space`、`Shift + Command + R` |
| 隐藏当前窗口 | 全局快捷键，或窗口内 `Command + W` |
| 翻到下一页，假装在看需求文档 | 阅读区获得焦点后按 `←` / `→`；使用官网自己的翻页逻辑 |
| 挪开遮住表格的书 | 按住 `Option` 拖动阅读区；拖动窗口边缘可缩放 |
| 回书架 / 调设置 | 菜单栏书本图标，或窗口内 `Command + ,` |
| 返回选书页 | 窗口内 `Command + Esc`，或设置菜单中的「返回选书页」 |
| 刷新网页 | `Command + R`，或设置菜单中的「重新加载」 |
| 退出 | 设置 →「退出轻读」，或窗口内 `Command + Q` |

默认不显示 Dock 图标，也没有应用工具栏。阅读窗口浮在普通应用窗口上方；隐藏时会从屏幕上移走，不会缩成 Dock 里的小窗口。**隐藏的是窗口，不是进程**：活动监视器里仍能看到它。系统安全界面或整台 Mac 卡住时，也别指望快捷键替你救场。

如果隐藏了菜单栏书本图标，必须先保留可用的全局快捷键。真把入口忘了，从 Finder 再次打开 app，可以恢复窗口和菜单栏入口。设置和窗口位置会自动保存，下次打开沿用。

## Windows 原型：暗号暂时不能换

Windows 11 x64 原型启动后只保留托盘入口，阅读窗口默认隐藏，首次显示后才加载网页。全局显示 / 隐藏快捷键固定为 `Alt + 0`（主键盘数字 0），按住 `Alt` 拖动窗口；官网模式下，窗口激活时按 `Alt + Esc` 返回选书页。当前不支持切换或自定义，也没有设置持久化。快捷键被占用时，仍可用托盘菜单。Windows 原型尚未作为上面的 macOS Release 发布。

## 这本书为什么能“融入环境”

- 阅读背景默认完全透明（不透明度 0%），正文是金色 `#D4AF37`、苹方中等字重，并带细暗色轮廓。封面和插图保留原色。
- 阅读页隐藏官网顶部导航、侧边栏和底部工具栏，也藏起上一页 / 下一页按钮；方向键仍交给官网处理。想回书架，从原生菜单选择「回到微信读书首页」。
- 阅读页采用 100% 页面缩放，正文行高约 1.55、段间距 0.6em；书架和独立登录页保持正常比例。排版样式在网页脚本测量正文前注入，避免首轮与后续分页尺寸打架。
- 透明适配只用于 `weread.qq.com` 的阅读页。书架、登录框和笔记弹窗保留正常背景；遇到特殊书籍底色或官网改版，可以关闭透明背景或恢复易读外观。降低整个窗口不透明度也能淡化底色，但文字会一起变淡。

WebKit 原生底色通过运行时检查后调用 `drawsBackground` SPI 关闭。这不是公开 API；接口不可用时应用会提示，系统升级后也需要重新验证透明效果。

## 关于“老板看不见”的科学边界

轻读只有一个系统 WebKit 网页容器，不打包 Chromium，也不定时轮询、自动刷新、截图或识字。隐藏时先移走原生窗口，再处理菜单和焦点，不等待网页脚本或网络。网页仍留在内存中，以便快速恢复。

这不代表“零占用”。2026-09-28 在一台 macOS 26.3 机器上的单次快照：原生进程约 40.6 MB，WebContent 约 377.3 MB，GPU 约 21.3 MB，Networking 约 18.9 MB，合计约 458 MB；空闲 CPU 约 0–0.2%。书籍和页面不同，数字会变。隔离测试里，网页 JavaScript 忙碌时原生隐藏调用耗时 4.27 ms；这是函数耗时，不是按键到画面消失的完整时间，更不是电脑卡死时的承诺。

书架、阅读进度、笔记和时长都由微信读书官网处理。轻读不调用私有同步接口，也不把凭据写进项目文件；额外保存的只有外观设置、窗口位置和最后一个官方阅读页地址。**隐藏后是否继续计算阅读时长，不作保证。** 登录后的进度和笔记跨设备同步仍需人工验证，不能把官网支持同步等同于这个版本已测通。

## 想自己编译？

只需要 Apple Command Line Tools，不需要第三方运行时或完整 Xcode：

```bash
bash mac/scripts/test.sh
bash mac/scripts/test-window.sh
bash mac/scripts/test-appearance.sh
bash mac/scripts/build-app.sh
```

本地产物在 `mac/build/轻读.app`，对应构建机器的架构，使用临时签名。现有测试覆盖策略与快捷键注册、网页忙碌时隐藏 / 恢复、透明像素、DOM 与 Canvas 金色正文、翻页按钮隐藏和签名校验。方向键没有被重复接管，但真实书籍翻页、长章节性能、跨设备同步，以及多桌面 / 全屏应用中的快捷键表现，仍需要实际使用验证。

轻读不会帮你完成日报；它只负责在日报之间，留一页书的位置。
