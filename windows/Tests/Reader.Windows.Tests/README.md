# Windows 原型验收

第一阶段，目标为 Windows 11 x64；需要 .NET 10 SDK 构建、Evergreen WebView2 Runtime 运行。构建脚本优先使用仓库 `.build/dotnet/` 中的本地 SDK，没有时使用系统 `dotnet`。exe 与托盘使用 `windows/Resources/AppIcon.ico` 中的金色书本 Logo。默认不访问官网。自动测试拦截全部 WebView 请求，夹具通过模拟官网地址测试 Windows 网页脚本，不使用真实账号；浏览器运行时自身的后台活动不在此拦截范围内。

```powershell
powershell -File windows/scripts/test-windows.ps1
windows/build/Qingdu.Windows.exe
# 明确打开官网，登录与阅读需人工验证
windows/build/Qingdu.Windows.exe --website
```

正常启动只显示托盘入口，不自动显示阅读窗口；按 Ctrl + ↑ 或托盘菜单后才显示窗口并初始化网页。默认加载离线夹具，`--website` 加载官网，不修改系统开机启动设置。

自动验证：原生句柄已创建时窗口仍隐藏且未激活，显式恢复后首轮排版与重注入一致、DOM 与 Canvas 六色切换及像素、分页尺寸不变、插图原色、颜色保存与重新加载、网页透明像素、工具栏隐藏、原生窗口在网页持续忙碌时隐藏和恢复。测试输出只含固定检查名及耗时，不输出网页正文、账号或 Cookie。45 秒超时判失败。

字体颜色通过托盘菜单选择，保存于 `%LOCALAPPDATA%/Qingdu/text-color.txt`；缺失或非法值使用金色。自动测试使用独立随机配置目录，不修改真实用户颜色。

人工验收（自动 PNG 透明不等于桌面合成透明）：

- 把窗口放到浅色、深色及复杂桌面上，逐一选择六种字体颜色，确认正文和 Canvas 同时变色、插图不变、菜单勾选正确；重启及翻页后仍沿用所选颜色。
- 正常启动时确认窗口不出现、不抢焦点，托盘图标保留；第一次按 Ctrl + ↑ 后加载页面，反复隐藏／显示不会重新初始化网页或丢失当前阅读页。
- 在 100%、150%、200% 缩放和多显示器间验证文字、Alt + 拖动、窗口边缘缩放与鼠标点击；完全透明空白可能穿透点击，必须记录实际行为。
- 在其他应用中按 Ctrl + ↑，确认窗口消失、恢复；快捷键被占用时提示且托盘可恢复。Alt + F4 应隐藏，托盘退出应结束进程。
- 通过托盘切换深色底，验证透明不适用时可继续阅读。
- 官网模式从阅读页使用托盘「返回选书页」或在窗口激活时按 ↓，确认能回到微信读书首页；切到其他应用时 ↓ 保持该应用原有行为；←／→ 沿用官网翻页。按住 Ctrl + ↑ 仅切换一次，按住 ↓ 不反复导航。离线夹具不提供此入口。
- 任务管理器同时记录 Qingdu.Windows 和全部所属 msedgewebview2 子进程的 CPU、内存，比较静止、翻页、隐藏状态。WebView2CompositionControl 内部使用图形捕获，不能将此方案描述为没有捕获开销；应用不另加轮询、截图循环或自动刷新。
- 官网模式需扫码后验证阅读与翻页；手机进度、笔记同步需用户配合验证。

当前原型不提供：快捷键配置、除字体颜色以外的设置与窗口位置持久化、再次启动恢复已有实例、安装器和发布签名。新开实例会有独立窗口；托盘入口始终保留。原型和自动测试各用独立 `%LOCALAPPDATA%/Qingdu/Prototype/<随机标识>/`，官网模式用 `%LOCALAPPDATA%/Qingdu/WebView2/Profile/`；按项目规则不会自动删除这些缓存。

滚轮模式人工验收：托盘「翻页方式」切换到鼠标滚轮，阅读窗口右上角出现 ×，重启后模式保留。在官网阅读页聚焦轻读后，下滚下一页、上滚上一页，快速滚动受 300ms 限频；其他应用获得焦点时，鼠标悬停轻读滚动不得翻页。书架正常滚动；× 应立即隐藏并保留页面，Ctrl + ↑ 恢复；切回方向键模式隐藏 ×。实际 WebView2 输入路由及鼠标设备行为必须在 Windows 验证，macOS 交叉构建不等同通过。
